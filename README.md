# Prudêncio Checklist

Sistema de checklist de segurança para operadores de empilhadeiras industriais.

## Funcionalidades
- ✅ Checklist digital de início e fim de turno
- ✅ Gestão de frota e manutenção corretiva
- ✅ Ranking de operadores por pontuação
- ✅ Relatórios e histórico de inspeções
- ✅ Assinatura digital e evidências fotográficas
- ✅ PWA com funcionamento offline
- ✅ Dashboard com KPIs e score de conformidade
- ✅ QR Code para identificação de máquinas

## Tecnologias
- HTML5, CSS3, JavaScript (Vanilla)
- PWA (Service Worker)
- LocalStorage para persistência
- Lucide Icons
- QRious para geração de QR Codes

### Telas Principais
1. **Dashboard** - Visão geral da frota e indicadores
2. **Checklist** - Realização das inspeções
3. **Manutenção** - Abertura e acompanhamento de OS
4. **Ranking** - Pontuação dos operadores
5. **Treinamentos** - Material de capacitação
6. **Perfil** - Dados do operador logado
7. **Admin** - Gestão completa do sistema
